# 推理预算：把「想多久」变成显式旋钮

## 四个档位

| level | extra_tokens | 适用 |
|---|---|---|
| none | 0 | 简单/高频，直接答 |
| low | 64 | 常规问答 |
| medium | 192 | 需要几步推理 |
| high | 512 | 复杂证明/长链 |

## 难度估计（廉价启发式）

```
score = min(len(q)/120, 1)
      + 0.1 * 疑问词密度（why/how/prove/explain…）
      + 0.15 * 算术/符号标记
```

真实系统里用一个轻量路由器模型（`reason/router.py`）替换启发式，训练目标是
「用最浅的档位还答对」——即算力-质量权衡的显式化。
