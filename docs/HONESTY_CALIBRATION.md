# 诚实度与置信度校准

## 三种失败模式

| 模式 | 现象 | 危害 |
|---|---|---|
| 过度自信 | 置信度高但常错 | 幻觉（最危险） |
| 欠自信 | 置信度低但常对 | 过度弃答，浪费能力 |
| 校准漂移 | 分布偏移后失效 | 线上退化 |

## 度量：ECE

期望校准误差把置信度按桶分箱，比较每个桶的平均置信度与平均准确率的差距。
ECE 越低越校准良好。见 `merlin/honesty.py`。

## 修法

- **温度缩放**：对置信度 logit 除温度，压低过度自信；
- **弃答阈值**：把「我不确定」做成显式动作，截断幻觉路径。
